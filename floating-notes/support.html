English

Floating Notes attaches rich, local-first notes to text selections, images, or elements on web pages, with bilingual English and Arabic (RTL) support.

Quick start & shortcuts

  • Capture a note: Select text (or right-click a page/image) and click Add note, use the context menu, or open the extension toolbar button.
  • Allow automatic restore per site: To keep notes and markers visible on future visits, grant optional site access for that site from the capture prompt or inside the side panel. You can revoke site access at any time without deleting saved notes.
  • Focus Reader: Press Alt+Shift+R (or open Focus Reader from the side panel / context menu) for a distraction-free reading view with bundled Latin & Arabic fonts and translation support.

Optional AI, translation & sync setup

  • AI features (off by default): Open Settings → AI & translation, opt in explicitly, and save your own OpenRouter (free :free models only) or Groq API key. Keys stay only in local Chrome extension storage on your device.
  • Translation: Uses Chrome’s on-device Translator API when available, or optional Azure / DeepL credentials configured in Settings (with explicit per-origin permission).
  • Cloud sync & account deletion: Optional via Settings → Sync & data using email OTP or Google sign-in. You can sign out (keeping or wiping local data), delete only your cloud copy, or permanently delete your account from the Danger Zone inside Settings.

Troubleshooting & diagnostics

  • Notes stay private inside your browser’s local IndexedDB (floating-notes). Export a full JSON backup anytime from the Library or Settings.
  • To inspect extension health safely, click Export diagnostics in Settings. Diagnostics contain only app/database versions, theme/language settings, allowed-site count, and sync status—never your note text, URLs, emails, or API keys.
  • Privacy policy: https://7usien.github.io/floating-notes/privacy.html

العربية

تتيح لك إضافة «الملاحظات العائمة» (Floating Notes) إرفاق ملاحظات غنية ومحلية أولاً بالكلمات أو الصور أو العناصر داخل صفحات الويب، مع دعم كامل للعربية واتجاه من اليمين إلى اليسار (RTL).

البداية السريعة والاختصارات

  • إنشاء ملاحظة: حدّد أي نص في الصفحة (أو اضغط بزر الفأرة الأيمن على نص أو صورة) واختر إضافة ملاحظة، أو افتح أيقونة الإضافة في شريط Chrome.
  • تفعيل الظهور التلقائي لكل موقع: لإبقاء الملاحظات والعلامات ظاهرة تلقائيًا عند زيارة الموقع مجددًا، اسمح للإضافة بالوصول إلى ذلك الموقع وحده من إشعار الحفظ أو من السايد بار. يمكنك سحب الإذن في أي وقت دون حذف ملاحظاتك.
  • قارئ التركيز (Focus Reader): اضغط Alt+Shift+R أو افتحه من السايد بار / قائمة الصفحة للقراءة الهادئة مع خطوط عربية ولاتينية مدمجة والترجمة والملخصات الذكية.

إعداد الذكاء الاصطناعي والترجمة والمزامنة الاختيارية

  • الذكاء الاصطناعي (معطّل افتراضيًا): من الإعدادات ← الذكاء والترجمة، فعّل الخيار وأضف مفتاحك الخاص من OpenRouter (النماذج المجانية فقط) أو Groq. تبقى المفاتيح محليًا على جهازك فقط.
  • الترجمة: تعمل محليًا على الجهاز عند توفر مترجم Chrome، أو عبر Azure / DeepL فقط بعد اختيار المزوّد وحفظ مفتاحه والموافقة على إذن النطاق الخاص به.
  • المزامنة وحذف الحساب: اختيارية عبر الإعدادات ← المزامنة والبيانات (برمز بريد OTP أو Google). يمكنك الخروج مع إبقاء البيانات المحلية أو مسحها، أو حذف النسخة السحابية فقط، أو حذف الحساب نهائيًا من الإعدادات.

حل المشكلات والتشخيص الآمن

  • تُحفظ بياناتك محليًا في متصفحك داخل IndexedDB (floating-notes)، ويمكنك دائمًا تصدير نسخة احتياطية JSON أو ملفات Markdown من المكتبة أو الإعدادات.
  • عند الحاجة لفحص حالة الإضافة، استخدم تصدير التشخيص من الإعدادات؛ فهو يضم أرقام الإصدارات وإعدادات الواجهة وعدد المواقع وحالة المزامنة فقط، ولا يتضمن أي نصوص ملاحظات أو روابط أو مفاتيح.
  • سياسة الخصوصية: https://7usien.github.io/floating-notes/privacy.html
