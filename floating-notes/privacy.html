English

This policy describes the Floating Notes Chrome extension. It applies on 2026-11-28 at its public address (https://7usien.github.io/floating-notes/privacy.html). Questions and support requests go to https://7usien.github.io/floating-notes/support.html.

Local by default

Floating Notes stores notes on the device. An account is not required, and the extension does not send note content anywhere unless you use one of the optional features below. There is no advertising and no default telemetry.

On this device, IndexedDB (database floating-notes) holds:

  • page address, title, site name, favicon address, and language
  • the anchor that ties a note to a part of the page
  • note title, rich text, plain text, tags, and optional labels such as kind, layer, and space
  • a local change log and your settings, including which sites you allowed
  • per-note saved AI summaries and flashcards (note.aiArtifacts / aiNoteArtifacts), stored on this device, included in JSON backups, and synced only when you enable optional cloud sync

A small picture of the anchored block may be stored on the device to help you relink a note. Those pictures stay on the device. They are left out of JSON backups and are not synced.

Chrome extension storage on this device also holds settings, optional sync status, and, if you save them, your Azure, DeepL, or optional OpenRouter / Groq AI API keys. Optional AI keys stay strictly on-device, are excluded from backups and diagnostics, and are used solely for direct HTTPS requests to your chosen AI provider when you invoke AI features. A sign-in session is stored there only after you sign in.

A JSON backup you export includes pages, anchors, notes (including saved AI summaries and flashcards attached to notes), tags, the change log, and settings. It includes the list of sites you allowed. It does not include block pictures, translation keys, or AI keys. Markdown export contains the note text you choose to export.

Optional AI features

Floating Notes includes optional AI capabilities (smart auto-tagging cloud_auto, page/site summarization, and stateless AI study cards exportable as Markdown or Anki TSV) that remain off by default. They require your explicit opt-in and consent, and use:

  • BYOK (Bring Your Own Key) OpenRouter (Free Models Only): makes direct HTTPS requests from the extension background worker to openrouter.ai using your own OpenRouter API key saved locally on this device. Only zero-cost free models (openrouter/free and :free models) are listed and allowed.
  • BYOK (Bring Your Own Key) Groq: makes direct HTTPS requests from the extension background worker to api.groq.com using your own Groq API key saved locally on this device to run active Groq chat models.

Optional AI results (such as summaries and generated study cards) may be temporarily cached in browser session memory (storage.session) during the current session to avoid duplicate requests. Session cache entries are cleared when Chrome closes and are never synced or included in backups.

When AI is disabled or unconfigured, zero requests are made.

Optional site access

The extension can capture a note on the current tab after you click the toolbar button, use the page menu, or run a command. Keeping notes visible on later visits requires you to allow that one site. You can refuse or revoke that grant. Revoking it stops automatic restoration and does not delete the notes already saved.

Optional dictation

When you start dictation, Chrome’s speech recognition may process the audio, including on Google servers. Floating Notes inserts the resulting text into the note. It does not store or sync an audio recording.

Optional translation

The default translator runs on your device when Chrome provides it. Article text is sent to Azure or DeepL only after you select that provider and save a key on this device. Connecting to Azure or DeepL uses an optional per-origin host permission requested when you configure that provider. The request is made from the extension’s background worker. The key remains on this device.

Optional sync

Sync is off until you sign in. It uses HTTPS with the Supabase project built into that version of the extension. Notes are not end-to-end encrypted. The signed-in account can hold page records, anchors, note content, tags, a device cursor, and the sync change log. Sign-in is an email code or Google, if you choose Google.

You can sign out and keep notes on this device, sign out and remove this device’s notes, delete the cloud copy, or delete the account. Deleting the cloud copy leaves the account in place. Deleting the account removes the cloud copy and the sign-in user when the account-deletion service is available for that project. Removing the extension removes its local extension data through Chrome.

Diagnostics

If you choose Export diagnostics, the file contains the app and database versions, language, theme, whether local tag suggestions are on, the count of allowed sites, the count of pending changes, and the sync state. It does not contain note text, page addresses, email addresses, or keys.

محلية افتراضيًا

تخزّن «الملاحظات العائمة» الملاحظات على الجهاز. الحساب غير مطلوب، ولا تُرسل الإضافة محتوى الملاحظات إلى أي مكان إلا إذا استخدمت ميزة اختيارية مما يلي. لا إعلانات ولا تتبّع افتراضي.

على هذا الجهاز، يحتفظ IndexedDB (قاعدة floating-notes) بما يلي:

  • عنوان الصفحة وعنوانها الظاهر واسم الموقع وعنوان الأيقونة واللغة
  • المرساة التي تربط الملاحظة بجزء من الصفحة
  • عنوان الملاحظة والنص الغني والنص العادي والوسوم، وتسميات اختيارية مثل النوع والطبقة والمساحة
  • سجل تغييرات محلي وإعداداتك، بما فيها المواقع التي سمحت بها
  • الملخصات وكروت المراجعة المحفوظة لكل ملاحظة (note.aiArtifacts / aiNoteArtifacts)، وتُحفظ على هذا الجهاز وتُضمّن في النسخ الاحتياطية JSON وتُزامَن فقط عند تفعيل المزامنة السحابية الاختيارية

قد تُحفظ صورة صغيرة للكتلة المربوطة على الجهاز للمساعدة في إعادة الربط. تبقى هذه الصور على الجهاز، وتُستبعد من نسخ JSON الاحتياطية، ولا تُزامَن.

تخزين الإضافة على هذا الجهاز يحتفظ أيضًا بالإعدادات وحالة المزامنة الاختيارية، ومفاتيح Azure أو DeepL أو مفاتيح OpenRouter / Groq الاختيارية للذكاء الاصطناعي إذا حفظتها. تبقى مفاتيح الذكاء الاصطناعي محلية بالكامل على الجهاز، ويتم استبعادها من النسخ الاحتياطية والتشخيص، ولا تُستخدم إلا لطلبات HTTPS المباشرة لمزوّد الذكاء الذي تختاره عند تفعيل مزايا الذكاء الاصطناعي. تُحفظ جلسة الدخول هناك فقط بعد تسجيل الدخول.

نسخة JSON التي تصدّرها تشمل الصفحات والمراسي والملاحظات (بما فيها الملخصات والكروت المحفوظة معها) والوسوم وسجل التغييرات والإعدادات، ومنها قائمة المواقع المسموح بها. لا تشمل صور الكتل ولا مفاتيح الترجمة ولا مفاتيح الذكاء الاصطناعي. تصدير Markdown يحتوي نص الملاحظات الذي تختاره.

مزايا الذكاء الاصطناعي الاختيارية

تتضمن «الملاحظات العائمة» مزايا ذكاء اصطناعي اختيارية (الوسم التلقائي الذكي cloud_auto، وتلخيص الصفحات والمواقع، وكروت المراجعة الذكية اللحظية القابلة للتصدير بصيغة Markdown أو Anki TSV) والتي تبقى معطلة افتراضيًا. تتطلب هذه المزايا موافقتك واختيارك الصريح، وتعمل عبر:

  • مفتاحك الخاص (BYOK) من OpenRouter (النماذج المجانية فقط): يرسل طلبات HTTPS مباشرة من عامل الخلفية للإضافة إلى openrouter.ai باستخدام مفتاح API الخاص بك المحفوظ محليًا على هذا الجهاز، وتقتصر القائمة والتنفيذ على النماذج المجانية فقط (openrouter/free ونماذج :free).
  • مفتاحك الخاص (BYOK) من Groq: يرسل طلبات HTTPS مباشرة من عامل الخلفية للإضافة إلى api.groq.com باستخدام مفتاح Groq API الخاص بك المحفوظ محليًا على هذا الجهاز لتشغيل نماذج الدردشة النصية النشطة.

قد تُخزَّن نتائج الذكاء الاصطناعي الاختيارية (مثل الملخصات وكروت المراجعة المولّدة) مؤقتًا في ذاكرة جلسة المتصفح (storage.session) خلال الجلسة الحالية لتجنب تكرار الطلبات. تُمسح هذه البيانات تلقائيًا عند إغلاق Chrome ولا تتم مزامنتها أو تضمينها في النسخ الاحتياطية مطلقًا.

عندما يكون الذكاء الاصطناعي معطلاً أو غير مُعد، لا يتم إجراء أي طلبات شبكة.

الوصول الاختياري إلى الموقع

يمكن للإضافة التقاط ملاحظة في التبويب الحالي بعد ضغط زر الشريط أو استخدام قائمة الصفحة أو تشغيل أمر. إبقاء الملاحظات ظاهرة في الزيارات التالية يتطلب السماح لذلك الموقع وحده. يمكنك الرفض أو سحب الإذن. سحب الإذن يوقف الاستعادة التلقائية ولا يحذف الملاحظات المحفوظة.

الإملاء الاختياري

عند بدء الإملاء، قد يعالج تعرّف Chrome الصوت، بما في ذلك على خوادم Google. تُدرج «الملاحظات العائمة» النص الناتج في الملاحظة. لا تخزّن تسجيلًا صوتيًا ولا تزامنه.

الترجمة الاختيارية

المترجم الافتراضي يعمل على جهازك عندما يوفّره Chrome. يُرسل نص المقال إلى Azure أو DeepL فقط بعد اختيار ذلك المزوّد وحفظ مفتاح على هذا الجهاز، ويتطلب الاتصال بخدمة Azure أو DeepL إذن مضيف اختياري خاص بالنطاق يُطلب عند إعداد المزوّد. يصدر الطلب من عامل الإضافة في الخلفية. يبقى المفتاح على هذا الجهاز.

المزامنة الاختيارية

تبقى المزامنة متوقفة حتى تسجّل الدخول. تستخدم HTTPS مع مشروع Supabase المضمّن في ذلك الإصدار. الملاحظات ليست مشفّرة طرفًا لطرف. يمكن للحساب الذي دخلت به أن يحتفظ بسجلات الصفحات والمراسي ومحتوى الملاحظات والوسوم ومؤشر الجهاز وسجل تغييرات المزامنة. الدخول برمز بريد أو عبر Google إذا اخترت Google.

يمكنك الخروج مع إبقاء ملاحظات هذا الجهاز، أو الخروج مع حذف ملاحظات هذا الجهاز، أو حذف النسخة السحابية، أو حذف الحساب. حذف النسخة السحابية يُبقي الحساب. حذف الحساب يزيل النسخة السحابية ومستخدم الدخول عندما تتوفر خدمة حذف الحساب لذلك المشروع. إزالة الإضافة تزيل بياناتها المحلية عبر Chrome.

التشخيص

إذا اخترت تصدير التشخيص، يحتوي الملف على إصداري التطبيق وقاعدة البيانات، واللغة، والمظهر، وهل اقتراح الوسوم المحلي مفعّل، وعدد المواقع المسموح بها، وعدد التغييرات المعلقة، وحالة المزامنة. لا يحتوي نص الملاحظات ولا عناوين الصفحات ولا البريد ولا المفاتيح.
